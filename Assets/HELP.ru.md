# Инструкция: mdview

**mdview** — лёгкий просмотрщик Markdown-файлов для Windows (.NET 8 + WPF).
Markdown конвертируется в стандартный `FlowDocument` и отображается штатными средствами WPF.
Вот всё, что нужно знать для работы.

## Открытие файлов

| Способ | Как |
|---|---|
| Меню | «Файл → Открыть…» (Ctrl+O) |
| Перетаскивание | перетащите `.md`-файл в окно |
| Командная строка | `mdview.exe readme.md` — можно несколько файлов (откроется первый) |
| Обновить | F5 перечитывает текущий файл с диска |

Поддерживаемые расширения: `.md`, `.markdown`, `.mdown`, `.mkd`, `.txt`.

## Поддерживаемая разметка

- Заголовки h1–h6, абзацы, списки (маркированные, нумерованные, вложенные)
- Task-списки `- [x]` / `- [ ]` с единым стилем чекбоксов
- Таблицы с выравниванием колонок (`:---`, `:---:`, `---:`)
- Блоки кода с **кнопкой «Копировать»** (иконка) и **подсветкой синтаксиса**
- Цитаты `>`, горизонтальные линии `---`
- Форматирование: **жирный**, *курсив*, ~~зачёркивание~~, `встроенный код`,
  верхний/нижний индекс (`x^2^`, `H~2~O`)
- Ссылки: внешние открываются в браузере, **относительные `.md`-ссылки — в этом же окне**
- Картинки: локальные (относительно папки файла) и по http/https

### Подсветка кода

- Включена по умолчанию, отключается в «Вид → Подсветка кода».
- Схема зависит от темы: **VS Code Light+** / **VS Code Dark+**.
- Подсвечиваются: комментарии, строки, числа, ключевые слова, вызовы функций.
- Длинные строки не переносятся — появляется горизонтальная прокрутка.

## Оглавление

Ctrl+T показывает/скрывает боковую панель с заголовками документа.
Клик по заголовку — переход к разделу.

## Темы и язык

- «Вид → Тема»: **Авто** (как в Windows), **Светлая**, **Тёмная**. Выбор запоминается.
- «Вид → Язык»: **Как в системе**, English, Русский. Переключение мгновенное.
- Тёмная тема перекрашивает меню, скроллбары и заголовок окна.

## Печать и экспорт

- **Ctrl+P** — печать текущего документа (штатный диалог печати).
- **Ctrl+S** — сохранить документ как XPS-файл.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | Открыть файл |
| F5 | Обновить текущий файл |
| Ctrl+T | Оглавление |
| Ctrl+P | Печать |
| Ctrl+S | Сохранить как XPS |
| Ctrl+колесо | Масштаб |
| Ctrl + / Ctrl − | Масштаб |
| Ctrl+0 | Сбросить масштаб |
| Alt+F4 | Выход |
