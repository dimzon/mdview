# Добро пожаловать в mdview

Это **демонстрационный файл** для проверки всех возможностей просмотрщика: *курсив*, ***жирный курсив***, ~~зачёркнутый текст~~, `встроенный код`, H~2~O (подстрочный), E = mc^2^ (надстрочный).

## Форматирование

| Функция | Пример | Статус |
|:--------|:------:|-------:|
| Жирный | `**текст**` | ✔ |
| Курсив | `*текст*` | ✔ |
| Зачёркивание | `~~текст~~` | ✔ |
| Верхний/нижний индекс | `x^2^` / `H~2~O` | ✔ |

## Код

Блок кода с подсветкой шрифта:

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Привет, mdview!");
    }
}
```

А это длинная строка кода, чтобы проверить горизонтальный скролл: `dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true /p:RuntimeIdentifier=win-x64`.

    Также это блок кода с отступом (indented code).
